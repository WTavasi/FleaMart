# FleaMart
This is a Java application created in liason with three other group members to create a working interface for a mock e-commerce platform for school businesses to manage their products, track their deliveries and interact with newer customers. The application also has a customer-side interface that allows a customer to sign up/login, make orders and view available products.
The application was built using NetBeans IDE's Drag & Drop Feature to build the GUI, MySQL used as the database language.
The file has been uploaded in a .zip file format and contains the necessary JDBC driver that we used.
